AFRICA UNIVERSITY STUDENT SUCCESS & DEVELOPMENT PORTAL

Open Africa_University_Student_Success_Portal_All_Features.html in Chrome or Edge.
Demo role login: select a workspace, enter any non-empty ID and password.

Included: existing portfolio/student life/staff functions, achievement review, recommendation workflow, industrial attachment, CV generation, document centre, scholarship board, mentorship requests, alumni profile, secure-sharing preview, notifications and aggregate demo analytics.

IMPORTANT: This is a browser-local prototype. Data is stored in localStorage in the current browser. It is not connected to Africa University systems or a shared database. The secure profile sharing feature creates a local demo token only. Sample academic results and sample scholarship listings are illustrative and not official.
